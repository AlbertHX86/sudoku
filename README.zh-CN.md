# 数独

[English](README.md) | 中文

一个在浏览器里运行的极简数独。没有广告，不用注册，也没有任何依赖。它是 [舒尔特方格](https://github.com/AlbertHX86/schulte-grid) 的姊妹游戏，外观一致。

**在线试玩：** https://alberthx86.github.io/sudoku/

## 怎么玩

1. 选择难度：**简单**（40 个已知数）、**中等**（32 个）或 **困难**（26 个）。每道题都是新生成的，并且只有唯一解。
2. 点一个空格，再点棋盘下方的数字。填入第一个数字时开始计时。
3. 填满棋盘，使每一行、每一列、每个 3×3 宫都恰好包含 1–9。
4. 填错的数字会变红，“错误”加一。点 ⌫ 可以擦掉。
5. 棋盘全部正确时停止计时，成绩自动保存到“记录”。
6. 点击“重置”换一道新题。

辅助功能：

- 选中格子后，会高亮它所在的行、列、宫，以及所有相同的数字。
- 某个数字已经正确填满 9 次后，对应的按钮会变灰。
- 键盘操作：<kbd>1</kbd>–<kbd>9</kbd> 填数，<kbd>Backspace</kbd> 或 <kbd>0</kbd> 擦除，方向键移动。

右上角可以切换亮色和暗色，以及中文和英文。默认跟随系统主题和浏览器语言。

## 记录

每个难度单独记录：最佳成绩和最近 10 局，并记下每局的错误次数。记录保存在浏览器的 `localStorage` 里，不会上传到任何地方。

- 同一设备的同一浏览器会一直保留记录，在线离线都可以。
- 不同浏览器、不同设备之间不同步。
- 清除浏览器数据会删掉记录。也可以点“清空”，删除当前难度的记录。

## 本地运行

游戏只有三个静态文件：`index.html`、`style.css`、`app.js`，不需要构建。

```bash
git clone https://github.com/AlbertHX86/sudoku.git
cd sudoku
```

然后直接用浏览器打开 `index.html`，或者起一个本地服务：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

直接打开文件和通过 `localhost` 访问，在浏览器看来是两个不同的网站，记录分开保存。

## 数独与大脑

解数独需要在工作记忆中保留候选数字、运用规则并检查选择，这些都是前额叶皮层的核心功能。脑成像研究显示，解题时前额叶和额顶控制区域明显活跃；经常做数字谜题的人，在注意力和记忆测试中往往得分更高。不过这类研究数量少、样本小，也不能说明玩数独会改变大脑。网页中的“文献”部分有带引用的简要综述。
